# Reverse Clip Editor Implementation Plan

> Implement inline with executing-plans; verify the entire branch before PR.

**Goal:** Make precise short-video selection and output review usable on phones and desktop.
**Architecture:** Extend the existing single HTML and conversion state, retaining pinned WASM and generation guards. Native video/canvas builds a bounded thumbnail strip; the existing real encoder also renders drafts.
**Tech Stack:** Native JS, HTML/CSS, FFmpeg WASM, PowerShell, Node/Python tests.
**Spec:** docs/superpowers/specs/2026-11-06-editor-design.md

## Global Constraints
- Single HTML, connect-src 'none', no user-media upload, JA/EN, mobile 320px.
- Preserve 15fps default, 0.5s minimum, 10s/1080p5s limits and immutable runtime locks.
- 30fps: experimental <=720px/5s; draft <=360px/15fps/silent.

## Review Focus
- Replacement/cancel during thumbnail decode must release old video and reject stale canvases.
- Long-source zoom must include both boundaries and permit full-view restoration.
- Settings changes during render must invalidate old outputs and re-enable controls.
- Shared filenames must be sanitized and unsupported/cancelled sharing must retain output.
- 30fps reverse/pingpong/AAC must preserve duration, counts and endpoint order.
